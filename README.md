# 知秋

一个适合手机端的极简 PWA，包含日记、备忘、摘录三个板块，并提供普通日记与 321 日记格式。321 日记固定记录当天感恩的三件事、让当天变好的两件事或感悟，以及一条自我肯定，并带有独立日期。

## 使用

将 `outputs` 目录部署到任意静态网页托管服务后，用手机浏览器打开即可。支持：

- 日记、321 日记、备忘、摘录（文案 / 干货）、专注切换
- 摘录支持上传图片、预览图片和 OCR 识别图片文字
- 图片识别第一次使用需要联网下载识别引擎和中文识别包；如果网络波动，可点击“重新加载识别”
- 专注提供 15 / 25 / 50 分钟计时
- 专注提供 15 / 25 / 50 分钟计时，并记录完成次数
- 日记可选择线条猫猫头心情
- 可按月份翻阅日记本，并通过“导出 PDF”保存为电子日记本
- 新建、编辑与删除记录
- 本机 `localStorage` 保存，不上传内容
- 一键导出 JSON 备份，也可以恢复备份
- 数据同时保存到 IndexedDB 与本机存储，并会请求浏览器保留站点数据
- Service Worker 离线缓存
- 支持浏览器的“添加到主屏幕 / 安装”

直接双击 `index.html` 也可以预览界面，但离线缓存与安装能力需要通过 `http://` 或 `https://` 访问。

## 永久链接与多设备

本地 `index.html` 路径不是永久链接。要获得不会失效的 HTTPS 地址，需要完成 Netlify 或 GitHub Pages 部署。

当前版本的数据仍然保存在设备本地，因此手机和电脑不会自动同步。跨设备同步需要接入云端数据库（例如 Supabase 或 Firebase）并配置账号权限；在完成配置前，请使用“备份 / 恢复”迁移 JSON 数据。
